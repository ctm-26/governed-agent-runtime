# Evidence and Claims Policy

Every substantive document should distinguish:

- **Fact:** directly supported by a cited source or measurement.
- **Inference:** a conclusion drawn from stated facts.
- **Hypothesis:** a testable proposition not yet established.
- **Decision:** a chosen project rule or design, which may be revised.
- **Limit:** missing information or uncertainty that constrains the claim.

## Source hierarchy

1. Standards and official specifications
2. Original peer-reviewed papers
3. Original preprints, clearly labeled
4. Official implementation documentation
5. Reproducible project experiments
6. Secondary summaries for discovery only

## Version discipline

Record the specification version, publication date, model/runtime version, dataset revision, and access date when those details can change the result.

## Novelty claims

Do not claim an idea is novel because we have not seen it before. Novelty requires a documented search and a narrower statement describing what combination, invariant, protocol object, benchmark, or result appears distinct.
