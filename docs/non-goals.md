# Non-goals

The initial project will not:

- bypass platform terms, access controls, rate limits, or unsupported interfaces;
- automate social-account changes through emulators or covert UI simulation;
- store every available personal datum merely because it can;
- treat model confidence as authorization;
- let memory, reflection, or learned skills change permissions;
- infer successful task completion from a successful API response alone;
- claim reinforcement learning, causal learning, or continual learning without an appropriate definition and evaluation;
- train a general language model from scratch before the data and task are justified;
- promise regulatory compliance as a property of the software alone;
- split into many repositories before module boundaries are proven.
