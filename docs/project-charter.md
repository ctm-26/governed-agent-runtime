# Project Charter

## Purpose

Develop and evaluate a model-agnostic control plane for agents that:

1. represent intended world-state changes explicitly;
2. execute only through declared capabilities and independent authorization;
3. record expected and observed outcomes with provenance;
4. distill repeated, trustworthy experiences into versioned skills;
5. improve competence without learning additional authority;
6. remain inspectable, testable, reversible, and interoperable.

## Primary deliverables

- an open specification
- machine-readable schemas
- a deterministic reference runtime
- conformance and adversarial test suites
- a reproducible research benchmark
- adapters to existing standards rather than a replacement for them

## Success criteria

The project must eventually demonstrate, against strong baselines:

- improved task completion on related later tasks
- reduced correction and unnecessary-action rates
- retention of earlier capabilities
- complete provenance for promoted skills
- bounded data access
- zero executed authority violations in the evaluated scope

## Evidence discipline

A compelling architecture diagram is not evidence of learning, safety, causality, or novelty. Claims must be linked to tests, measurements, primary sources, or clearly labeled hypotheses.
