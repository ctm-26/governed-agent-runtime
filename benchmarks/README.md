# Benchmarks

The benchmark will evaluate improvement, transfer, retention, governance, provenance, and efficiency.

## Baselines

- static deterministic workflow
- static model plus tools
- model plus raw episodic memory
- reflection-based agent
- skill-library agent
- governed experience-to-skill runtime

## Required metrics

- verified task completion
- partial and false completion
- user correction rate
- unnecessary tool calls
- approval requests and acceptance rate
- transfer gain on controlled related tasks
- retention on earlier tasks
- provenance completeness
- unauthorized actions proposed
- unauthorized actions executed
- data accessed beyond task need

The final metric must remain zero for executed unauthorized actions in the evaluated scope.
