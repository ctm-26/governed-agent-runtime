# Research Library

This directory tracks primary sources and official specifications relevant to governed continual-learning agents.

## Themes

- continual and lifelong learning for language agents
- skill generation, consolidation, and drift
- tool-using agents and approval workflows
- authorization, intent, and confused-deputy risks
- provenance and reproducibility
- human oversight and action verification
- software supply-chain security

## Rules

- Label preprints as preprints.
- Summaries must state what a source demonstrates and what it does not demonstrate.
- Record versions for living specifications.
- Add contradictory and negative results, not only supporting work.
